## Sobre

O Conselho do Dia é um site de reflexão diária baseado no estoicismo. A cada dia ele traz uma ideia de pensadores como Sêneca, Marco Aurélio e Epicteto, com uma pergunta para pensar e uma pequena ação para praticar — tudo em poucos minutos.

Também é possível explorar reflexões por tema, guardar as que fizerem sentido e conhecer alguns exercícios estoicos.

## Por que fiz

Queria um lugar simples e calmo para voltar todo dia, sem excesso de informação, e que levasse a sério a origem de cada frase — muitas citações “estoicas” que circulam por aí não são de quem dizem ser.

Também foi uma forma de praticar desenvolvimento front-end com HTML, CSS e JavaScript puro, cuidando de design, responsividade e acessibilidade.

## Como rodar

Não precisa instalar nada: basta clonar o repositório e abrir o `index.html` no navegador.

```bash
git clone https://github.com/kaua698/estoicismobased.git
```
